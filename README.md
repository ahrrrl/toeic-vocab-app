# 📚 공기업/공무원 종합 학습 핸디북 (Study Handbook App)

이 프로젝트는 구글 스프레드시트를 데이터베이스로 활용하여 토익, 한자 같은 단순 단어 암기부터 **행정학과 같이 방대한 이론 구조 파악과 기출문제 풀이가 필요한 과목**까지 모두 학습할 수 있는 Next.js 기반 종합 웹 애플리케이션입니다.

## 🚀 주요 기능

- **구글 시트 연동:** 과목별(토익, 한자 등) 구글 시트의 탭(토픽) 이름과 단어 목록(단어, 뜻, 예문)을 자동으로 불러옵니다.
- **다중 과목 및 맞춤형 UI 지원:** `src/config/subjects.js` 설정을 통해 여러 개의 구글 스프레드시트를 각각 독립적인 과목으로 분리합니다. 과목의 특성(단어장 vs 이론서)에 따라 서로 다른 최적화된 UI가 렌더링됩니다.
- **일반 단어장 모드 (토익, 한자 등):** 깔끔한 플래시카드 형태의 퀴즈 UI입니다. 카드를 스와이프하거나 클릭해 정답(뜻, 예문)을 확인하고, 무작위 셔플 기능을 통해 단순 암기 반복 학습을 돕습니다.
- **심화 핸디북 모드 (행정학 등 이론 과목):** 
  - **계층형 요약집 탭:** `중단원 > 소단원 > 개념`의 3단계 폴더 구조로 전체적인 숲(체계)을 파악하기 좋습니다. 개념을 클릭하면 상세 내용을 편안하게 읽을 수 있는 모달 팝업이 제공되며, 팝업 내에서 이전/다음 개념으로 빠르게 이동할 수 있습니다.
  - **O/X 스피드 퀴즈 탭:** 실전 기출 지문을 모바일 화면에서 빠르게 [O] [X] 버튼으로 풀고 즉각적으로 해설을 확인하는 실전 감각 훈련 UI를 제공합니다.
- **어르신/약시자를 위한 접근성 (글자 크기 조절):** 시력이 불편하신 분들을 위해 화면 우측 상단에 `A-` / `A+` 버튼을 배치하여 전체 글자 크기를 조절할 수 있습니다. 설정한 폰트 크기는 사용자 브라우저(로컬 스토리지)에 자동 저장됩니다.
- **빠른 속도 및 비용 최적화 (ISR):** 구글 시트 데이터를 매번 불러오지 않고 캐싱하여 주기적(기본 1시간)으로만 업데이트하므로, 구글 API 호출 한도(Quota)를 절약하면서도 매우 빠른 페이지 로딩 속도를 제공합니다.

## ⚙️ 설정 및 실행 방법

### 1. 구글 스프레드시트 준비하기
1. 학습할 내용에 맞춰 새로운 구글 스프레드시트를 생성합니다. (예: "토익 필수 영단어", "천자문 한자장" 등)
2. 하단의 시트 탭을 추가하여 학습 단위를 나눕니다. (예: "1일차", "2일차")
3. 각 시트 탭의 첫 번째 줄(1행)은 제목으로 비워두고, 두 번째 줄(2행)부터 아래 양식에 맞추어 작성합니다.
   - **일반 단어장 (토익/한자 등) 양식 (A~C열):**
     - **A열:** 단어 (예: Accommodate / 學)
     - **B열:** 뜻 (예: 수용하다, 숙박시키다 / 배울 학)
     - **C열:** 예문 (예: The hotel can accommodate 500 guests.)
   - **행정학 핸디북 양식 (A~F열):**
     - **A열 (유형):** `개념` 또는 `OX`
     - **B열 (중단원):** 예: 정책결정
     - **C열 (소단원/그룹):** 예: 의사결정 모형
     - **D열 (키워드/기출지문):** 예: 쓰레기통 모형 / 쓰레기통 모형은 합리성을 강조한다.
     - **E열 (내용/해설):** 예: 우연한 기회에 의해 결정... (개념 상세 내용 또는 OX 해설)
     - **F열 (OX 정답):** OX일 경우에만 `O` 또는 `X` 입력

### 2. 구글 클라우드 서비스 계정 발급받기
1. [Google Cloud Console](https://console.cloud.google.com/)에 접속합니다.
2. 새 프로젝트를 생성하고 **Google Sheets API**를 검색하여 사용 설정(Enable)합니다.
3. **서비스 계정(Service Account)**을 생성하고 JSON 형태의 키 파일을 발급받아 다운로드합니다.
4. JSON 파일을 메모장으로 열어 `client_email`과 `private_key` 값을 확인합니다.
5. **중요:** 앞서 만든 단어장 구글 스프레드시트의 우측 상단 '공유' 버튼을 누르고, 방금 확인한 `client_email` 주소를 추가하여 뷰어(Viewer) 권한을 부여합니다. (앱이 시트를 읽을 수 있게 해줍니다)

### 3. 로컬 환경 변수 설정
프로젝트 폴더(루트 경로)에 `.env` 파일을 만들고 아래의 내용에 맞게 채워 넣습니다. (`.env.example` 파일을 복사해 사용하셔도 됩니다.)

```env
GOOGLE_SHEETS_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n여기에_프라이빗_키를_붙여넣으세요\n-----END PRIVATE KEY-----\n"
GOOGLE_SHEETS_CLIENT_EMAIL="서비스계정_이메일주소@project.iam.gserviceaccount.com"

# 과목별 스프레드시트 ID
SPREADSHEET_ID_TOEIC="토익_스프레드시트_ID를_여기에_넣으세요"
SPREADSHEET_ID_HANJA="한자_스프레드시트_ID를_여기에_넣으세요"
SPREADSHEET_ID_PA="행정학_스프레드시트_ID를_여기에_넣으세요"
```
*(스프레드시트 ID는 브라우저 주소창 URL `docs.google.com/spreadsheets/d/이부분이_ID입니다/edit` 에서 확인 가능합니다)*

> **새로운 과목을 추가하려면?** 
> `src/config/subjects.js` 배열에 새 과목을 추가 등록하고, `.env` 에 해당 스프레드시트 ID를 추가해주기만 하면 코딩 수정 없이 새 과목이 연동됩니다.

### 4. 로컬 환경에서 실행하기

의존성 패키지를 설치하고 개발 서버를 시작합니다.

```bash
npm install
npm run dev
```

설치가 끝나면 브라우저에서 `http://localhost:3000` 으로 접속하여 앱을 사용하실 수 있습니다.
